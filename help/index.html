Getting started

  1. Open a blank QGIS project. Press FiberQ Schematics on the toolbar or select it in Vector → FiberQ Schematics.
  2. Use Workspace → New for a new GeoPackage, or Open for an existing schematic. Changes are saved immediately.
  3. For a ready-to-use example, open Workspace → Demonstrations → Demo. Choose a new file. The network and splice examples are also available.
  4. Use Draw for equipment and cables, Edit for selection and movement, and Fibers for optical connections.
  5. Use Reports for route reports, checks, materials, optical budgets, legends and settings. Workspace exports PDF, SVG and DXF.

Fiber tools

Snap highlights exact free cable ends, cut ends and equipment connectors. Join connects two free endpoints; Group join connects consecutive pairs. Cut opens a fiber or existing join. Through restores a cut. Click a joined fiber to highlight its connected path; open cuts stop continuity. Fiber data applies purpose along that path.

Branch diverts existing free A/B ends. A is the drawing start and B the finish. Choose a count and free end, click inside the first fiber, then place the diverted end ahead and to one side. Connect it using Join. Restore route returns the selected fiber to the cable path; use Select cable to restore the bundle. Restore cuts with Through first.

Esc or right-click cancels placement. Undo and Redo are available for edits in the current session.

Workspaces

Keep the GeoPackage with your project. Save project writes a QGIS project beside it. Reopen the GeoPackage in FiberQ to continue editing. Older workspaces migrate to a separate copy; the original is preserved.

EPSG:3857 values are schematic drawing positions. Optical budgets use entered real cable lengths. Use separate schematic GeoPackages and start in a blank project.
