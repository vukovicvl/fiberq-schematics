# FiberQ CAD toolbar icons

These 35 bitmap files are unmodified 32-pixel assets extracted from `FiberQ.cuix`
in the supplied FiberQ CAD 1.0.0 bundle.

Copyright (c) 2026 Vladimir Vukovic. The MIT notice is retained in
[FIBERQ_CAD_LICENSE.txt](../../FIBERQ_CAD_LICENSE.txt).

`ribbon.py` treats bitmap black as transparent and adapts grayscale strokes to
the current Qt text color when displaying the icon. The source files remain
unchanged. Standard workspace/edit commands use QGIS theme icons instead.

Milestone 7 adds the source cut, through, group-join, branch, slack, description,
type and fiber-purpose icons (`FQ_PRS`, `FQ_PRO`, `FQ_SPG`, `FQ_ODV`, `FQ_REZ`,
`FQ_OPIS`, `FQ_KVRS`, `FQ_KBOJ` and `FQ_NM1` through `FQ_NM10`).
